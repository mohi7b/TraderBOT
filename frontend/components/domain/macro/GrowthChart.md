# GrowthChart — چارت «رشد اقتصادی» (GDP Growth)

> سند فنی کنار کامپوننت (قاعدهٔ پروژه). «چرا»ها این‌جاست، نه فقط «چه»ها.
> خانوادهٔ ظاهری: `shahrivar_growth` — **هم‌خانوادهٔ** `CpiYoyChart` و `PolicyRateChart`.

---

## ۱) جایگاه در صفحه

سومین چارت `app/dashboard/macro/page.tsx` (بلافاصله **زیر** چارت تورمی و چارت نرخ بهره)
تا سه شاخص اصلی اقتصاد یک کشور در یک صفحه قابل‌مقایسه باشند.
دادهٔ آن از گروه اختصاصی **`1E_growth_core`** (`/api/growth-core`) می‌آید و به
استخر مشترک صفحه merge می‌شود (`mergeGroups`).

## ۲) داده (canon اختصاصی `GDP_GROWTH`)

| ورودی پرامپت | وضعیت واقعی | منبع |
|---|---|---|
| GDP YoY | ✅ | OECD `GDP_VPV_YOY` / `GDP_YOY` · **مشتق** از ایندکس سطح یا زنجیرهٔ QoQ |
| GDP QoQ SAAR | ✅ | OECD `GDP_VPV_QOQ` · Eurostat `GDP_CLV_PCH_SM` · FRED `GDPC1` (سطح، USA) |
| Potential GDP | ⚠️ پروکسی مستند | «روند ۴فصلی سطح» (سری رسمی منتشر نمی‌شود) |
| Trend Growth (4Q) | ✅ محاسبه‌شده | میانگین متحرک ۴فصلی سری رشد (خط کمکی خاکستری نقطه‌چین) |
| PMI Manufacturing / Services | ❌ **موجود نیست** | هیچ providerی PMI منتشر نمی‌کند ⇒ بج `PMI —` سفید |
| GDP Nowcast | ❌ **موجود نیست** | منبع Nowcast در pipeline نیست ⇒ بج `NOW —` سفید |
| Population | 🚫 استفاده‌نشده | هیچ فرمول پرامپت به آن نیاز ندارد |

**چرا مشتق‌گیری؟** پوشش منابع یکسان نیست (نمونهٔ واقعی):
`AUS/BRA/JPN/ZAF` هر دو سری خام دارند · `DEU/FRA/ITA` فقط QoQ Eurostat ·
`USA` فقط سطح `GDPC1` (۳۱۸ نقطه) · `TUR` فقط YoY · `CAN/GBR/KOR/SAU` یک نقطه ✗.
پس: **YoY** از سطح یا زنجیرهٔ QoQ و **QoQ** از سطح محاسبه می‌شود (تبدیل ریاضی
دادهٔ منتشرشده، نه جعل)؛ مبدأ در `data-growth-yoy/qoq` و tooltip و ردیف توضیحات
(`computed (سطح/زنجیرهٔ QoQ)`) صریح است.

**گارد کهنگی:** سری‌ای که آخرین فصلش بیش از **۶ فصل** از مرجع عقب‌تر است رد
می‌شود (تجربه: `MEX` تا 2022-Q4 · `RUS` تا 2010-Q4) ⇒ به‌جای نمایش عدد کهنه،
بج `—` و حالت empty.

## ۳) فرمول‌های GAS

| جزء | فرمول (کد: `lib/macro/growth.ts`) |
|---|---|
| `GMI` | مومنتوم رشد = (Δ۱+Δ۳ رشد YoY) + (Δ۱+Δ۳ رشد QoQ) — نبود QoQ ⇒ فقط YoY (مستند) |
| `OGI` | شکاف تولید = `(سطح آخر / میانگین ۴ فصل قبل − ۱)×۱۰۰` |
| `GSI` | σ گام‌های YoY در ۸ فصل اخیر (کمتر = پایدارتر) |
| `GAPg` | رشد YoY − میانگین ۴ فصل قبل |
| `GFT` | **۰٫۴×Current + ۰٫۶×Future** · `Current=norm(GDP YoY, −۲..۶)` · `Future=norm(0.6·GMI+0.4·GAPg, ±1)` |
| `Stability%` | `clamp(100 − σ/σ_ref×100, 0, 100)` با `σ_ref=2.0` |

**نگاشت خروجی به بج اصلی (پرامپت):**
| خواسته پرامپت | پیاده‌سازی |
|---|---|
| پس‌زمینه = GFT (۴ سطح) | `gft ≥0.75` سبز · `≥0.5` زرد · `≥0.25` نارنجی · وگرنه قرمز (`GFT_TONE`) |
| فلش = روند | `sign(GMI + PMI)`؛ PMI موجود نیست ⇒ سهم صفر ⇒ عملاً `sign(GMI)` (در tooltip صریح) |
| زاویه = سرعت | `|GMI| ≥0.6` عمودی (`▲▼`) · `≥0.15` مورب (`↗↘`) · وگرنه افقی (`▷`) |
| تعداد = شدت | `(|GMI| + |OGI|)/1.7` ⇒ ۱/۲/۳ (نگاشت به `weight` بج) |
| رنگ متن = اثر بر بازار | `GMI` ≥+0.3 سبز · ≥۰ زرد · >−0.3 سفید · وگرنه قرمز |
| مقدار = پایداری | `Stability%` |

## ۴) سیگنال‌ها (یک خط، بدون شکست)

`Gas` → `GMI` → `OGI` → `GSI` → `PMI` → `NOW` → `GAPg` (هر هفت در یک سطر؛
`signals.max = 7` در تم). فقط `Gas` پس‌زمینهٔ رنگی و **شدت** دارد.

| id | برچسب | نمایش | رنگ متن |
|---|---|---|---|
| `gas` | `Gas` | `▲ 68%` | چهارسطحی از GMI (اثر بر بازار) + پس‌زمینه از GFT |
| `gmi` | `GMI` | `▲ +2.09` | ≥+0.3 سبز · ≥۰ زرد · >−0.3 سفید · وگرنه قرمز |
| `ogi` | `OGI` | `▲ +0.65%` | همان قاعده با آستانهٔ ۰٫۵ |
| `gsi` | `GSI` | `σ 0.93` | **معکوس**: σ≤۰٫۴ سبز · ≤۰٫۹ زرد · ≤۱٫۶ سفید · وگرنه قرمز |
| `pmi` | `PMI` | `—` | سفید (بدون منبع داده) |
| `now` | `NOW` | `—` | سفید (بدون منبع داده) |
| `gapg` | `GAPg` | `▼ −0.79pp` | همان قاعده با آستانهٔ ۰٫۵ |

⚠️ **قرارداد «بدون داده»** (`noDataSignal` در `lib/macro/macroSignals.ts`):
مقدار `—` · رنگ سفید · بدون فلش · بدون مقدار ساختگی. برچسب بسته به زمینه:
`Yld` در چارت نرخ بهره طبق درخواست کاربر `N/A` می‌شود، ولی در چارت رشد برچسب
`PMI`/`NOW` می‌ماند تا جای سیگنال در سطر مشخص باشد.

## ۵) رنگ‌ها (تم `shahrivar_growth`)

| مورد | مقدار |
|---|---|
| پس‌زمینه | `rgba(17,24,38,0)` (ترنسپرنت روی بدنهٔ کارت — مثل دو چارت قبلی) |
| خط اصلی (GDP YoY) | `gdpYoy = #a3e635` (سبز فسفری — سری یکتا) |
| خط دوم (QoQ SAAR) | `gdpQoq = #3b82f6` (آبی همرنگ چارت‌های قبلی) |
| روند ۴فصلی | `trend = rgba(148,163,184,0.75)` نقطه‌چین (سری کمکی خنثی) |
| بج‌ها | `badgeBg rgba(255,255,255,0.08)` · `statusTint 0.35` · `valuePlate 0.75` · فونت ۱۰ |
| `valuePlate 0.75` | متن مقدار «جلوتر» می‌نشیند و رنگش مطلق می‌ماند (AA) |

**نقاط داده:** **بدون نقطه** — فقط خطوط (به‌درخواست کاربر 2026-09-22؛ نسخهٔ
اول این چارت `markers: true` داشت و حذف شد).

**زوم و فضای آینده:**
| مورد | مقدار | توضیح |
|---|---|---|
| زوم | `zoom: "3Y6M"` = **۴۲ ماه = ۳ سال و نیم** | زوم **زمان‌محور** است (`resolveZoomRange` از آخرین داده به عقب می‌رود) ⇒ برای دادهٔ فصلی هم واقعاً ۳٫۵ سال می‌شود، نه ۴۲ فصل |
| فضای خالی راست | `futureMargin: 4` | بر حسب **میله** اعمال می‌شود (`scrollToPosition`) ⇒ ۴ میلهٔ فصلی = **یک سال** خالی بعد از آخرین داده (تم‌های ماهانه ۱۲ دارند که برای فصلی ۳ سال می‌شد) |
| برچسب محور زمان | `timeScale.timeVisible: true` | تاریخ در محور برای دادهٔ فصلی دیده شود |
| `futureMargin: 12` در تم‌های دیگر | ⚠️ برای این چارت **اشتباه** بود | چون این چارت فصلی است و میله = فصل |
