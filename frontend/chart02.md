🎯 هدف
افزودن «هدف تورمی بانک مرکزی» برای هر کشور، به‌صورت دو کران (low/high) در دیتابیس اصلی ماکرو، و پاس‌دادن آن به فرانت‌اند برای استفاده در چارت‌های تورمی (LWC).
این داده نباید روی چارت رسم شود؛ فقط باید در بخش بالای چارت (Chart Meta Panel) نمایش داده شود.

۱) تغییرات دیتابیس اصلی (Main Macro DB)
جدول: macro_countries
دو فیلد جدید اضافه کنید:

Code
inflation_target_low   FLOAT NULL
inflation_target_high  FLOAT NULL
توضیح:
اگر کشور هدف ثابت دارد → هر دو مقدار برابر

اگر کشور هدف بازه‌ای دارد → low ≠ high

اگر کشور هدف رسمی ندارد → هر دو NULL

۲) مقداردهی اولیه (Seed Data)
این مقادیر را برای کشورهایی که در دیتابیس کور وجود دارند وارد کنید:

کشور	low	high
آمریکا (Fed)	2	2
اروپا (ECB)	2	2
بریتانیا (BoE)	2	2
کانادا (BoC)	2	2
ژاپن (BoJ)	2	2
کره جنوبی (BoK)	2	2
سوئد (Riksbank)	2	2
نروژ (Norges Bank)	2	2
سوئیس (SNB)	0	2
استرالیا (RBA)	2	3
نیوزیلند (RBNZ)	1	3
هند (RBI)	2	6
برزیل (BCB)	3	3
چین (PBoC)	NULL	NULL


۳) تغییرات بک‌اند (Core API)
مسیر API:
/api/macro/country/:code

دو فیلد جدید را در خروجی اضافه کنید:

Code
{
  country: "US",
  inflation_target_low: 2,
  inflation_target_high: 2,
  ...
}
نکتهٔ مهم:
کور معمولاً فقط reader دیتابیس اصلی است.

اگر این دو فیلد در دیتابیس اصلی اضافه شوند، کور به‌صورت خودکار آپدیت می‌شود.

اگر مدل جدا دارد، فقط کافی است دو فیلد جدید به مدل اضافه شود.

۴) تغییرات فرانت‌اند (LWC CPI Chart)
چارت باید این دو مقدار را بخواند:
Code
const { inflation_target_low, inflation_target_high } = countryMeta;
نمایش:
❗ مهم: هدف تورمی نباید روی چارت رسم شود.

به‌جای آن:

نمایش در Meta Panel بالای چارت:
نمونه:

Code
Inflation Target: 2%
یا اگر بازه‌ای باشد:

Code
Inflation Target: 2% – 3%
یا اگر NULL باشد:

Code
Inflation Target: — 
دلیل:
جلوگیری از شلوغی چارت

خوانایی بهتر

استاندارد جهانی (Bloomberg / TradingView / FRED)

تمرکز چارت روی سری‌های اصلی (Headline + Core)

۵) مراحل کار (Step-by-Step)
مرحله ۱ — دیتابیس
افزودن دو فیلد

مقداردهی اولیه با جدول بالا

مرحله ۲ — بک‌اند
افزودن دو فیلد به خروجی API کشورها

مرحله ۳ — کور
اگر کور reader است → خودکار آپدیت

اگر مدل دارد → افزودن دو فیلد جدید

مرحله ۴ — فرانت‌اند
خواندن دو فیلد جدید

نمایش هدف تورمی در Meta Panel

عدم رسم هدف تورمی روی چارت
